# Limitations

- No successful IBM Bob 2.0 session has yet been captured on this machine. Bob Shell is not installed and the supplied key was invalid/exposed.
- The checked-in canonical proof is generated by the deterministic demo driver, not claimed as an AI-discovered result.
- Aegis verifies evidence freshness; it does not prove that Bob's security conclusion is semantically correct.
- The current file journal is local JSON, suitable for a hackathon proof rather than multi-user production.
- Crash consistency relies on atomic rename but has not been tested with forced process termination.
- There is no GitHub/GitLab PR adapter, public deployment, CI workflow, external user validation, or production telemetry yet.
- The existing marketing UI contains sample data. Only the canonical proof page and machine-verification commands constitute evidence.
